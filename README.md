# FinixCode Event Management Web App

A modern web application for managing sports events and activities, built with Next.js 13, TypeScript, and Tailwind CSS.

🔗 [Live Demo](https://finixcode-task-omega.vercel.app)

## Features

- 📱 Responsive design optimized for all devices
- 🎨 Modern UI with custom Tailwind CSS styling
- 💬 Interactive comments system with nested replies
- 🏃‍♂️ Event details with player management
- 🔄 Similar events carousel
- 🎯 Customizable UI components
- 🌈 Custom color theming system

## Tech Stack

- [Next.js 13](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Radix UI](https://www.radix-ui.com/)
- [Swiper](https://swiperjs.com/)
- [Lucide React](https://lucide.dev/)
- [Class Variance Authority](https://cva.style/docs)
- [TailwindMerge](https://github.com/dcastil/tailwind-merge)

## Getting Started

### Prerequisites

- Node.js 16.8 or later
- pnpm (recommended) or npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/finixcode-task.git
cd finixcode-task
```

2. Install dependencies:

```bash
pnpm install
```

3. Run the development server:

```bash
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
pnpm build
pnpm start
```
